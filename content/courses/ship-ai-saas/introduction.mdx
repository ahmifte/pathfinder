## What you'll build

By the end of this course you will have shipped a real AI SaaS: a working product
with authentication, Stripe subscriptions, per-plan usage limits, and an AI
feature — deployed and able to take money.

This intro lesson is free. It covers the architecture and the decisions that
matter before you write any code.

## The stack

- Next.js App Router for the full-stack app
- NextAuth for authentication
- Prisma + PostgreSQL for data
- Stripe for subscriptions
- An LLM provider for the core feature

## The mindset

The hard part of a SaaS is not the AI — it is the boring plumbing around it:
auth, billing, limits, and a funnel. We build that plumbing once, correctly, so
every future product starts from a solid base.
